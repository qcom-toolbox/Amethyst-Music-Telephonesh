# Changelog since 1.0

Changes since the [1.0](https://github.com/qcom-toolbox/Amethyst-Music-Telephonesh/releases/tag/1.0) release (June 23 – August 6, 2026).

## New features

- **Bulk Download** — added a new Bulk Download screen/flow, plus supporting changes to the view model, offline library, and track downloader; added translated strings for it in all locales.
- **Refresh downloads option** (#24) — resolves a suggestion to let users refresh their downloaded content.

## Bug fixes

- **Casting support fixed** — reworked `MusicPlayer`, `MusicPlaybackService`, and `AmethystCastOptionsProvider` to fix Chromecast playback.
- **#18** — fixed offline mode incorrectly triggering when the phone is locked and nothing is playing.
- **#20** — fix in `FullPlayerScreen.kt` (player screen behavior).
- **#21** — fixed songs restarting when un-selecting shuffle/random mode.
- **#22** — fixed song categories being generic/not connected to the server.

## Other

- Minor `EditTrackDialog` tweaks with translated strings across locales.
- README updates and an APK rebuild in the repo.
